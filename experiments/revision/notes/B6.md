# B6 Line goal for the pair standoff (referee m16)

Scripts: experiments/revision/B6_static.py, B6_quench.py, B6_analyze.py -> data/derived/rev_B6.json; force and
checks in B5_lib.py. Raw data: data/revision/B6/{static,quench}.jsonl. Queued (not run): B6_gen.py.

## Line goal in the code (checked)

With w2_goal = "line", Simulation.step replaces each agent's goal at every step by the nearest point of the segment
x = 11, y ∈ [5 − w/2 + r_i, 5 + w/2 − r_i] (BottleneckScenario.line_goals); this is used for steering only. For a
member at y ≈ 4.59 with r = 0.25 m, the goal moves from (11, 5) to (11, ≈4.9), which weakens the drive's push towards
the axis. The drive c_i e_i, with e_i = −∇ dist(x_i, goal segment), is still a gradient. The static force evaluates
line_goals at every call; its Jacobian asymmetry is ≤ 2.3e-10 relative.

## (a) Static check and 120 s quench

**Static.** Start the members from the point-goal snapshot positions. Relax with the line-goal C1 rest force (v = 0,
densities frozen, b = 0; pairlib.relax rules), then polish with Newton. Apply the B5 checks: Hessian −sym(J) positive
definite, contact-free, x < 10, opposite sides, front of jambs.

**Result: 46 of 46 remain strict minima**, all contact-free and in front of the jambs; no relaxation frees a member.
The members move by 8–48 mm (median 22 mm). The softest stiffness rises slightly: μ1 = 69–128 N/m (median 100),
against 65–121 N/m (median 94) with the point goal. The ratio line/point is 1.04–1.07.

**Quench.** C1, CF ∪ {B_w: 0.04} ∪ {w2_goal: line}, dt = 0.01 s, 120 s, deterministic stationary stop (the
e7b_quench runner, unchanged).

**Result:** all 46 unperturbed runs are held and stop stationary, as are all 230 replays displaced by 1e-9 m (seeds
900–904). The point-goal control is held in 46 of 46. Static and quench agree in 46 of 46. Cost: 322 runs,
10.6 CPU-min, one worker.

## (b) Generation with the line goal — queued, not run

B6_gen.py reruns the E7b_lib generation: the same 320 seeds (242–561), C1, w = 0.8 m, 100 agents, 600 s cap, flags
CF ∪ {B_w: 0.04} ∪ {w2_goal: line}, runner runlib.whole_run (unchanged), snapshots in data/revision/B6/library/.
B6_analyze.gen_summary counts, seed-matched against data/E7b/e7b_lib.jsonl (point goal):
- completions and deadlocks;
- pair standoffs (e7b_lib.qualifies);
- pair-or-group standoffs: deadlocks whose blocker, the residual agent nearest (10, 5), has a negative stuck-alone
  margin, a proxy for the keystone class "collective";

with exact McNemar p on each paired indicator.

Smoke test (--limit 1 --scale 0.05) passed. The job count is 320. Estimate ≈ 2.6–4 CPU-h (the point-goal E7b_lib took
2.6 CPU-h). Command: `experiments/revision/B6_gen.py`, then `B6_analyze.py`.

Context from earlier data: E7's line-goal cell (default walls, B_w = 0.08 m) gave 3 of 97 classified deadlocks as
collective, against 2 of 98 with the point goal. Its completion was 3 of 100, against 2 of 100.

## Claims

There is no change to the paper. The pair standoff persists under a line goal, at least for the existing library.
Part (b), once run, says whether pair standoffs also form under a line goal.
