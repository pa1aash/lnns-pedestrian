# A6 Second-trap rows for Table 3

Script: `experiments/revision/A6_second_trap_rows.py` -> `data/derived/rev_A6.json`; registry `notes/A6.yaml` (prefix `RevAsix`).
Existing data only (E2 library, `data/E2/e2_quench.jsonl`, stratum `lone_keystone_second_trap`, 26 snapshots). CPU about 1 min.

## What was done (definitions identical to the lone-keystone row)

- Freed: the blocker (`selection.json`) exits within 120 s.
- Noise σ = 0.07 m/s: each (snapshot, seed) run counts once, 5 seeds per snapshot, 130 runs (as `EtwoLKNoiseC*`).
- Force-coupled ORCA (RVO2): the unperturbed run per snapshot (26). The five 1e-9 m replays (perturb seeds 900-904, 130 replays) go only into the replay column.
- Δ: mean over snapshots of (k_i/5 − c_i), with a 95% percentile bootstrap over snapshots (2000, PCG64(12345)). The macro takes the value E2 `analyze.py` stored for this stratum, because the same code made `TabThreeLK*`. The script recomputes it from raw runs: the point value matches exactly, and a fresh-RNG interval [0.069, 0.43] is also stored.
- t_1/2: Kaplan–Meier median using the E2 `analyze.py` `km()`, with held runs censored at 120 s.
- J: Jaccard index of the unresolved sets, computed by `fix_a1.lone_block()`, the function behind `FixAoneLoneJ*`. A snapshot is noise-unresolved if k ≤ 2 of 5, and ORCA-unresolved if its unperturbed run holds. The interval is a two-level bootstrap. The independence value is the exact hypergeometric E J.
- Replay: for ORCA, the replays whose freed/held outcome differs from the unperturbed run. For noise, the snapshots whose five runs disagree.

- Unresolved sets: noise 3, ORCA 9, shared 2 (E1b_seed192, E1b_seed237). Exact P(J ≥ 0.20 | independent sets of sizes 3, 9 in 26) = 0.27. The overlap is indistinguishable from independence.
- On ORCA's unresolved snapshots, noise frees 37 of 45 runs; on ORCA's freed snapshots it frees 80 of 85. AUC 0.61 [0.44, 0.80], one-sided permutation p = 0.16. Noise frees almost every blocker that ORCA (RVO2) holds.
- Reference, force-coupled ORCA (legacy): 22/26 freed, and 5 of 130 replays change the outcome (these are the 5 legacy flips of Sect. 6.1).
- Lone-keystone row recomputed as a check: 148/170, 30/34, Δ = −0.01, t_1/2 = 19.8 and 1.5 s. All are identical to Table 3.

**Claim-relevant.** At the second trap, σ = 0.07 m/s is *not* fraction-matched at 120 s to force-coupled ORCA (RVO2): Δ = +0.25, and the CI excludes 0. It is matched to the legacy solver (Δ = +0.05 [−0.05, 0.18], see A8). The paper claims the match only at the lone keystone ("Per-step noise at σ=0.07 m/s, five seeds per snapshot, matches the rate of ORCA (RVO2)"), so no sentence becomes false. However, a second-trap row in Table 3 cannot be read as a rate-matched comparison. It shows a rate mismatch, with noise freeing more because ORCA's constraint part cancels part of its drive at the second trap (Sect. 6.1.4).
