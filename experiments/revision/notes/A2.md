# A2 Size of the ORCA density gate w_o

Scripts: `experiments/revision/A2_gate.py` (snapshots, bound, run summary) -> `data/derived/rev_A2.json`;
`experiments/revision/A2_runs.py` (reruns) -> `data/revision/A2/a2_runs.jsonl`; registry `notes/A2.yaml`.

## What was done
- Definition as coded: w_o = 1 − s(ρ; 4, 2), s(x; x0, c) = 1/(1 + e^{−c(x−x0)}) (rho_orca_fade 4.0, k_orca_fade
  2.0, code/config/params.yaml). ρ_i = N_i/(πR²), R = 3 m, N_i the other active agents within R (KDTree ball
  query over active positions, self excluded; code/sim/core/simulation.py). The gate has no density floor; the
  0.01 m⁻² floor in code/sim/steering/desired.py applies to the Weidmann factor only. Hence at ρ = 0,
  w_o = 1 − 1/(1 + e⁸) = 0.99966, not 1.
- Snapshots: w_o of every active agent at the saved rest state (the first quench step) of the 60 E2 lone-trap
  snapshots (selection.json E2) and the 46 E7b pair snapshots.
- Bound: N ≤ 99 within R in a 100-agent run, so ρ ≤ 99/(9π) = 3.50 m⁻² and w_o ≥ 1 − s(3.50) = 0.73.
  w_o < 0.99 needs ρ > 1.70 m⁻², i.e. N ≥ 49.
- Whole runs: neither w_o nor ρ is logged in the E6 records (Simulation.metrics_log holds max_density but is not
  saved). Reran the first 10 Sect. 6.2 seeds (242–251) of force-coupled ORCA (C3, CF flags with w2_orca = rvo2,
  w = 0.8 m, 100 agents, no noise, 600 s cap, stop at deadlock or completion; runlib.whole_run), with
  HybridSteeringModel.compute_forces wrapped at runtime (code/ unchanged) to record, every step, the minimum of
  w_o over the agents active at the start of the step. All 10 reruns reproduce data/E6/e6a.jsonl exactly
  (end time, completion, exit count). Time fraction = fraction of steps in which some agent has w_o < 0.99,
  pooled over the 3150 s of simulated time.

## Results
- Lone-trap snapshots (60, 137 agents, 1–9 active, N ≤ 8): w_o ∈ [0.9994, 0.9997].
- Pair snapshots (46, 2 agents each, N = 1): w_o = 0.9996 for every member.
  At every snapshot the gate lowers ORCA's rest drive by at most 0.06%.
- Analytic bound over any run: w_o ≥ 0.73 (ρ ≤ 3.50 m⁻²).
- Reruns: minimum over the 10 runs w_o = 0.958 (N = 69 within 3 m, ρ = 2.44 m⁻²); per-run minima
  0.958–0.963, reached 4.8–6.5 s after the start. Some agent has w_o < 0.99 during 13% of the simulated time
  (per run 38–44 s, all within the first 47 s), and no agent ever has w_o < 0.95.
  After the first 47 s of every run, w_o ≥ 0.99 for every agent; at deadlock it is 0.9994–0.9997.

## Interpretation
The gate is inactive in every regime the paper analyses: it is 1 to within 6·10⁻⁴ at all lone-trap and pair
snapshots and within 4.2% at the densest moment of a whole run (the initial crowd at the door). The mechanism
attribution (ORCA's rest drive, Sects. 5.1, 6.1) therefore does not depend on the gate; treating w_o = 1 at
rest changes the drive by < 0.1%. The analytic bound (0.73) is never approached: the room bottleneck never
packs more than 69 others within 3 m.

## Paper-claim flags
None contradicted. Sect. 3.2 calls the gate "gated off at high density"; at the densities reached here
(ρ ≤ 2.4 m⁻²) it never gates off, which the paper may want to state.
