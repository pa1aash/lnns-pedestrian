# Source for paper Table 4: conference claims and their status in this work

This file is the source for **Table 4** of the LNNS extended paper (Plan v1, plan/FINAL_PLAN.md §10) and for the one short paragraph in paper §6.3. Table 4 condenses these rows to: claim, status (confirmed / revised / withdrawn), evidence. Rows marked *pending* are decided by production runs. No correction notice to the proceedings is pursued (decision D-open-2); this file only feeds the paper. Table, figure and section numbers in the claim columns (e.g. "Table 4", "Fig 3", "Sec 4.6") refer to the **conference** paper.

Conference paper: Gang & Veluri, SIMULTECH 2026, pp. 474–481, DOI 10.5220/0015190200004094 (ref/camera_ready_SIMULTECH2026.pdf; text extract scan/probe_data/camera_ready.txt, cited as CR:line).

How to read this table:
- **Status:**
  - *confirmed*: the number or claim stands as printed;
  - *revised*: it stands in a changed form, or with a changed number;
  - *withdrawn*: the extension does not repeat it;
  - *pending*: the production experiment (E-number, plan/FINAL_PLAN.md §11) decides it.
- **Evidence** paths are relative to the plan root /Users/palaash/Developer/pedestrian-abs-plan.
- Labels:
  - VERIFIED: recomputed from stored files or re-run.
  - INFERRED: reasoned, not directly measured.
  - UNKNOWN: cannot be decided from what is stored.
- Wording rule for platform-dependent counts (decision D2, confirmed): the printed 0/25 and 13/25 are **n = 25 single-platform realisations that the published code reproduces on macOS**. The Windows draws (1/25, 7/25) go in a footnote as platform-sensitive. Large-n estimates with CIs lead.
