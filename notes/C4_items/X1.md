# X1 — Energy span of the barrier-library string paths (alternative analysis; no published number replaced)

Scripts experiments/revision5/X1_span_paths.py (runs) and X1_analyze.py → data/derived/rev5_X1.json; raw
data/revision5/X1/x1_paths.jsonl (132 paths, image energies and coordinates); scratch re-runs of the E3/E4 analyses in
data/revision5/X1/rean/ (not committed). Registry notes/C4_items/X1.yaml (prefix RxSpan, RxEfour, RxEthree, RxPool,
RxBeta).

## Method
- The gate (experiments/BAR/gate.py v2) kept only barrier, saddle and convergence numbers, not the images, so every
  accepted string (and the 4 rejected full strings) was recomputed with the gate's own functions (converge: 1500
  iterations at α = 4e-5, then up to two blocks of 500 at 1e-5 while F_perp ≥ 5 N; climb: |∇U| < 1e-2 N), the same end
  points and initial paths (straight; the axis path for the 5 pinned strings where the gate kept it) and the finer
  image count of the gate's accepted pair (62 or 124). 132 strings (60 alone, 36 pinned, 36 full; the 24 one-agent
  snapshots have alone = pinned = full). The recomputed climbing-image barriers equal the stored ones exactly
  (max relative difference 0.0): the stored strings are reproduced, not approximated.
- Path = images from the snapshot minimum s₀ to the exit, the first image with the blocker centre at x ≥ 10 m (the
  escape event of the runs). Beyond it the string keeps descending towards the goal and rises to the fixed end image,
  which is not a minimum; that tail is excluded (its maximum lies below the reported barrier on all 132 paths).
- ΔU_rep(img) = max E − E₀; ΔU_span(img) = max_{i<j}(E_j − E_i); interior minimum = zigzag extremum with a swing
  ≥ 0.05 J to the neighbouring maxima on both sides. Each interior minimum was relaxed (bar.relax, 20000 steps) to a
  rest state M and the gate's full check run from M to the same exit end point (31/62 images, 124 if the doubling
  rule fails), giving the exit barrier from M with the gate's verdict. "Affected" = |span − rep| > 1% of rep.
- ΔU_span used in the re-analysis carries the same climbing-image refinement as ΔU_rep: the published value when the
  span starts at s₀, else the climbing-image exit barrier from the relaxed M.
- Check: E1b_seed170 reproduces C3 (M2 21.87 J below s₀; exit barrier from M2 2.816 J, accepted).

"first saddle 0": the path descends from s₀ without first crossing a 0.05 J rise. Two kinds:
- **A** (46, 111, 130, 230, 237): ΔU_rep is the exit saddle, but measured from s₀; the path first drops into a deeper
  rest state M (6.0–12.9 J below s₀), so the climb to the exit is ΔU_rep + depth(M) (U_M + exit barrier = ΔU_rep to
  2%).
- **B** (60, 170, 223; rejected 75, 209): ΔU_rep is a small first saddle (0.02–0.13 J) into M (10.0–21.9 J below s₀);
  the exit saddle from M lies below s₀ and the exit barrier is 2.8–3.7 J (8.5 and 0.74 J for the rejected strings).
- In every affected path the blocker sits at x = 9.66–9.76 m in M, still upstream of the door plane: M is a second
  rest state of the same group, not an exit. The exit string from M is accepted by the gate rules in all 10 cases.
- Seeds 74 and 104 have a deeper M too, but the exit from M (0.62, 0.99 J) is lower than the first saddle (1.30,
  5.27 J), so the first saddle limits the rate and ΔU_rep is the span.

**Kramers rate with ΔU_rep is not the rate of escape to the exit** for the full condition of E1b seeds 46, 60, 111,
130, 170, 223, 230, 237 (barrier set) and of the rejected strings 75 and 209. In the pinned and alone conditions it is
the exit rate for all 56 snapshots.

At 0.07 m/s only seed46 crosses β = 1 (0.23 → 1.50); the other seven affected barriers rise but stay below 1 (170 0.28,
60 0.29, 223 0.32, 130 0.78, 111 0.91) or were already above (230 1.22 → 1.92, 237 1.13 → 1.84).

Physics: in the full condition the string from the snapshot can first pass a second rest state of the same group in
which the neighbours have moved and the blocker has not left. Where that rest state is deeper than the snapshot, the
escape rate is set by the climb out of it, the energy span, not by the highest point above the snapshot. This holds
for 8 of the 56 full barriers; the pinned and alone barriers, with only the blocker free, have no such state. The
substitution leaves the Arrhenius and pooled slopes inside their published intervals and removes the largest
full-condition ratio (seed237) and the largest time-step misfit, both from the same snapshot.
