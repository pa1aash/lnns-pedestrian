# CroMa 2021 bottleneck trajectories (subset)

- Dataset: CroMa 2021, Forschungszentrum Juelich (FZJ) pedestrian data archive, DOI 10.34735/ped.2021.9 (https://doi.org/10.34735/ped.2021.9).
- Licence: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/ (see the link for the terms).
- The distributed archive contains only the trajectory text files; it ships no separate readme, licence or metadata file.
- Format: PeTrack text export, 25 fps; columns id, frame, x/m, y/m, z/m, markerID.
