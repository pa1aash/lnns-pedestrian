## Reproduce

Every number, table and figure in the paper is regenerated from the per-run results committed under `data/`. The simulations that produced those results take about 164 CPU-hours (`experiments/queue.yaml`), so they are not part of the quick path below.

### 1. Requirements

- TeX Live 2024 or later with `latexmk`. A full TeX Live has everything. On BasicTeX, add the packages with
  `sudo tlmgr install latexmk cm-super type1cm pgf xcolor booktabs amsfonts latexpand`.
  The Springer class and BibTeX style ship unmodified in `paper/llncs/`, so there is nothing to install for them.
- poppler (`pdffonts`, `pdftoppm`, `pdfimages`), used by the figure checks.
- Python 3.13 (3.11 or later should work).

### 2. Python environments

```
make venv                       # .venv with requirements-figures.txt (numpy, scipy, matplotlib, pyyaml, colorspacious)
```

`make paper` runs `tools/make_numbers.py` and the table scripts with the `python3` on your PATH, which needs `numpy` and `pyyaml`. If that interpreter lacks them, run `. .venv/bin/activate` first.

The test suite needs a few more packages, pinned as in CI (`.github/workflows/tests.yml`):

```
python3 -m venv .venv-test
.venv-test/bin/pip install numpy==2.4.4 scipy==1.17.1 PyYAML==6.0.3 shapely==2.1.2 \
    pandas==3.0.2 pyarrow==23.0.1 matplotlib==3.10.8 pytest==9.0.2
```

### 3. Paper, numbers and tables (about 1 minute)

```
make paper        # regenerates paper/numbers.tex and paper/tables/*.tex from data/, then builds paper/main.pdf
git status        # should list no modified files: the regenerated numbers and tables are byte-identical
```

### 4. Figures 2-8 (about 30 seconds)

```
make figures      # runs figures/fig*.py with .venv/bin/python and prints pdffonts for each figure
```

The output is pixel-identical to the committed PDFs. Only the embedded creation date differs, so `git status` shows the figure PDFs as modified.

Fig. 1 is a Blender render (`experiments/hero/final.sh`, macOS only, about 2.5 minutes of render time and 3.6 GB of memory per panel; reports/HF_REPORT.md). The committed `figures/fig1_hero.png` is used as is. Its vector overlay is regenerated byte-identically by `python3 tools/make_fig1_overlay.py`.

### 5. Single-file submission

```
make submission   # writes paper/submission/ (main.tex with everything inlined, figures/, llncs.cls, splncs04.bst)
```

The script compiles the folder on its own in a temporary directory and reports how many `\pending` items are left.

### 6. Tests (about 6 minutes)

```
cd code && ../.venv-test/bin/python -m pytest -q -p no:cacheprovider
```

Expect 128 passed. The five failures are the bit-for-bit floating-point reference comparisons listed in `.github/workflows/tests.yml`; they depend on the platform and the BLAS build. The regression hash (`make -C experiments regress`) is checked only on the Mac where the reference was recorded.

### 7. Simulations (not part of the quick path)

The experiment drivers are under `experiments/E*/`. `experiments/queue.yaml` lists every step with its estimated CPU-hours. Run the queue with

```
make -C experiments queue PY=$(pwd)/.venv-test/bin/python
```

The `PY` override is required because the Makefile default is a path on the authors' machine. The queue target uses macOS `caffeinate`. On Linux, run `python experiments/queue.py run` with `PYTHONPATH=code` instead. The queue is resumable. A quick check that the simulator matches the recorded reference is `make -C experiments regress PY=$(pwd)/.venv-test/bin/python`, which takes about 7 s and must print `e381b49dc24acccd OK`. It is checked only on macOS. Raw trajectories for the CroMa comparison (`data/E10/raw/`, over 50 MB) are not in git. They are archived on Zenodo (DOI to be added at submission).
