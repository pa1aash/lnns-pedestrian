## Ranked defects

### HIGH

**H1. Table 3 runs 47.9 pt (about 17 mm) into the right margin.** Lines 1086-1109, tabular at 1090. It is visible on PDF page 16.
- Log: `Overfull \hbox (47.91664pt too wide) in paragraph at lines 1090--1109`.
- **Fix:** the table is generated by `experiments/tables/make_table3.py`, so change the generator, not `main.tex`.
  1. Set `\setlength{\tabcolsep}{1.5pt}` (saves about 24 pt over 8 columns).
  2. Head "Lower first" becomes "Lower".
  3. Print the ℓ cell of the C3 RVO2 row as `$-0.005$` instead of `$-4.8\times10^{-3}$`.
  4. Move the Arrhenius prediction "(2.22)" from the ℓ cell into the caption, which already defines ℓ.

  Together these save more than 48 pt. Do not use `\resizebox`: it would push the 7 pt `\scriptsize` text below 6 pt.

**H2. Following the README, `make figures` fails on a fresh clone.** Files: `README.md` (Build block) and `Makefile` (target `figures`).
- Output: `/bin/sh: ../.venv/bin/python: No such file or directory`, make error 1.
- The target needs `.venv`, which only the undocumented `make venv` creates.
- Section 9 of the paper (line 1182) says the repository holds "the scripts that build every figure".
- **Fix:** do either or both of the following.
  - Add `make venv   # creates .venv from requirements-figures.txt (once)` as the first line of the README Build block.
  - Make `figures` depend on the venv: `figures: .venv/bin/python` together with the rule `.venv/bin/python: requirements-figures.txt ; python3 -m venv .venv && .venv/bin/pip install -r requirements-figures.txt`.
